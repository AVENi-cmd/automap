# AUTOMAP Preview

Arabic RTL client preview, built from scratch with HTML, CSS and a small JavaScript file.

## Scope
Hero, four branches, four packages, WhatsApp booking links and footer. No booking form, reviews, trust section or structured SEO.

## Brand
Gold `#CBA945` is the most frequent gold RGB value sampled from the uploaded JPEG logo. Background `#090909`, cards `#151515`. Cairo headings and IBM Plex Sans Arabic body text.

## Run
Serve this directory using any static web server, for example `python -m http.server 4173`.

## Package assets
Generated with the built-in image generation tool and encoded as WebP without altering composition. Illustrative images, not photographs of AUTOMAP's actual premises. Files: `images/economic.webp`, `images/silver.webp`, `images/gold.webp`, `images/diamond.webp`.

Shared prompt: authentic documentary-style 3:2 automotive workshop photography; neutral overhead white lighting, natural paint imperfections and plausible reflections; only technician hands and forearms visible; no face, text, watermark, gold light strips, futuristic studio or showroom scene.
- Economic: white Toyota Camry; gloved technician applies ceramic coating using a microfiber applicator, plain bottle and detailing trolley.
- Silver: dark-gray Lexus ES; technician fits transparent PPF across the front 50 cm of the hood with a squeegee.
- Gold: silver Toyota Land Cruiser 300; technician fits a clear PPF sheet across the entire hood, with front fender and bumper visible.
- Diamond: white Nissan Patrol Y62; technician fits PPF to a closed passenger door, with a nearby protective film roll, representing full-body protection.

The approved service images were then edited with the supplied AUTOMAP logo reference: matte charcoal wall signage with the exact logo, a restrained gold `#CBA945` wall stripe or tool trolley trim, with vehicle geometry, service activity and neutral lighting preserved. Package images retain a 3:2 aspect ratio at all screen widths.

Each image and the stylesheet use a content hash in their URLs to avoid mixing cached and updated assets. Every SVG also has intrinsic dimensions.

Prices and branch contacts are supplied by the client. Diamond feature corrected to «نانو جنوط» based on the uploaded banner. «الأكثر طلبًا» is a proposed preview badge, subject to client confirmation.
